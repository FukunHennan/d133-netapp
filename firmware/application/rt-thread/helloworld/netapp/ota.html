升级过程中请勿断电、断网或操作串口。校验失败不会切换启动分区，可直接重试。

准备：运行 build.ps1 得到 ota.cpio；用 ota_manifest.py 打印 CRC32；在 images 目录启动 python -m http.server 8000 --bind 电脑IP。此为开发联调版：无签名验签，仅限可信局域网。
串口等价命令：netapp_ota http://电脑IP:8000/ota.cpio CRC32
